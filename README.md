## How to Replace the Website on GitHub

1. Open the [GitHub repository](https://github.com/raheelaly981-cpu/Raheel-Ahmed-Ideas-and-Works).
2. Click **Add file → Upload files**.
3. Upload `index.html`, `style.css`, and `script.js` from the website folder — not the ZIP file itself.
4. If GitHub asks whether to replace existing files, replace only these three files. Do not delete other files.
5. Scroll down to **Commit changes** and save to the main branch.
6. Wait a minute, then refresh the website.
